# 1. Product: scope and goals

**Priority:** P0

- [ ] 1.1 What is this: pet project / portfolio / commercial product / internal tool? This drives how deep the infrastructure goes and the required code quality.
- [ ] 1.2 Target audience: vinyl collectors? music lovers in general? a narrow niche (e.g. only certain genres/countries)?
- [ ] 1.3 Key value versus Discogs/MusicBrainz/RateYourMusic — why would a user come here? (language? community? UX? absence of a marketplace?)
- [ ] 1.4 Expected scale: 10 / 1,000 / 100,000 users; how many releases in the catalogue at launch and after a year.
- [ ] 1.5 Is the catalogue populated only by users from scratch, or imported from external databases? (critical for the UX of the first months)
- [ ] 1.6 Is monetisation planned at all? (ads, subscription, donations, none)
- [ ] 1.7 Marketplace (selling/trading records) — in scope, out of scope, or "maybe later"? Affects the collection data model.
- [ ] 1.8 Interface languages: Russian only / English only / i18n from day one.
- [ ] 1.9 What goes into the MVP (first working release) and what is explicitly deferred. State it in one paragraph.
- [ ] 1.10 MVP success criterion: what has to happen for us to call it a success.
- [ ] 1.11 Timeline and resources: are you working alone? how many hours per week? is there a deadline.
- [ ] 1.12 Your experience/preferences regarding the stack — what you already know well, what you want to try/learn on this project. (feeds [11.2](11-stack.md))
